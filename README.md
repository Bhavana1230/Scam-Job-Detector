# Scam Job Detector

A Streamlit-based machine learning prototype for identifying potential scam indicators in job advertisements.

## Features
- TF-IDF text feature extraction
- Logistic Regression classification
- Rule-based detection of suspicious job-posting indicators
- Interactive Streamlit interface

## Installation
Run `pip install -r requirements.txt` and then `streamlit run main.py`.

## Limitations
This prototype uses a small set of hard-coded examples and has not been validated for real-world scam detection.

## Disclaimer
For educational purposes only. Verify job offers through official company websites and trusted recruitment channels.
